Nerfed lets you decide exactly how hard you want things to be. Every debuff has its own adjustable levels, so you can go from a mild inconvenience to full chaos, and switch it off just as easily.

## Features

**Disabilities** (available now)
- **Adjustable levels:** every disability has its own strength levels, so you can set how bad it gets
- **Instant control:** turn them on or off at any time with simple commands
- **Condition viewer:** see which disabilities are active on you or another player
- **Simple Voice Chat support:** if [Simple Voice Chat](https://modrinth.com/plugin/simple-voice-chat) is installed, other players' voices are effected too

**Coming soon**
- **Random disabilities:** let the mod pick for you
- **More nerfs and debuffs:** Nerfed is just getting started, with plenty more planned beyond disabilites

Have an idea? Suggestions are welcome on the [issue tracker](https://github.com/Da5h1n/Nerfed/issues).

## Commands

| Command | What it does |
| --- | --- |
| `/nerfed disability <condition> <level>` | Set a disability's level (`0` turns it off) |
| `/nerfed disability limbs <limb> <level>` | Set a limbs disability's level |
| `/nerfed disability colourblind <type> <level>` | Set a colourblindness type and level |
| `/nerfed disability colourblind disable` | Turn colourblindness off |
| `/nerfed show [player]` | View active disabilities |

Tab-completion lists every available option, so you don't need to memorise anything.
